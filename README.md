## 三个只有细看条款才知道的限制

这部分是多数对比文章没讲透的地方，但对下单决策影响很大。

**第一，绿云特价机不退款，且无固定优惠码。** Budget Sale 系列在购买页明确标注 No refund/Money back；普通月付原价套餐也只有 7 天内且因系统故障才能申请退款。绿云的促销模式是“定期开仓补货 + 锁价年付”，没有搬瓦工那种长期有效的折扣码。所以实操上比较稳妥的路径是：先花 $6 买一个月付原价机，用你真实的网络环境测延迟和丢包，确认线路能接受，再去抢不退款的特价机锁价。有 VPS 博主还建议这类促销款用 PayPal 支付，多一层保障。

**第二，绿云对 CPU 长期占用有硬限制。** 连续 30 分钟以上跑满 100% vCPU 会触发限速甚至强制关机，转码、编译、挖矿这类持续高负载的业务要避开。它的 EPYC VDS 因为资源 100% 独享，更适合吃 CPU 的场景。另外绿云是 Unmanaged 无代管服务：客服响应速度确实快（官方口径工单平均 9 分钟回复、支持 Live Chat），但只负责底层网络和母机稳定，系统里装的软件出问题不归它管。

**第三，绿云换机房等于重新买。** 套餐按机房分货，买了东京想换新加坡，走的是重新下单而不是免费迁移——和搬瓦工 CN2 GIA-E 那种十几个机房自由切换的面板玩法完全不同。下单前想清楚机房，尤其是亚太机房流量还减半这件事。
